# Portfolio

Мой личный сайт-портфолио — одностраничник на FastAPI + Jinja2, без SPA-фреймворков, потому что для одной страницы это оверинжиниринг. Есть рабочая контактная форма (не просто mailto-ссылка): сообщения сохраняются в БД, опционально шлётся email-уведомление, есть honeypot и rate limiting от спама.

## Что внутри

- Одна страница: hero, обо мне, навыки, проекты (подтягиваются из списка в `main.py`), контакты
- Форма связи пишет в SQLite, с защитой от ботов (скрытое honeypot-поле) и лимитом 5 сообщений с одного IP за 10 минут
- Опциональная email-нотификация о новом сообщении через обычный SMTP

## Запуск

```bash
cp .env.example .env
docker compose up --build
```

Локально:
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Перед деплоем — обязательно поменять

В `app/main.py` в списке `PROJECTS` — ссылки на GitHub-репозитории. Сейчас там ожидаемые названия (`llm-rag-assistant`, `telegram-lead-bot`, `task-api-go`, `task-queue-go`), но нужно свериться, что репозитории реально называются так же, когда запушу — иначе ссылки будут вести в никуда.

## Тесты

```bash
pytest tests/
```

Проверяют валидацию формы и rate limiter — без поднятия сервера.

## Стек

FastAPI, Jinja2, SQLAlchemy, SQLite, Tailwind (через CDN), Docker
